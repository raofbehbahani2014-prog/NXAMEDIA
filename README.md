# NxMedia

سایت تولید محتوا و آموزش اینستاگرام — ساخته‌شده با Node.js (Express + EJS)

## اجرا
```bash
npm install
cp .env.example .env
npm start
```
سپس مرورگر را روی `http://localhost:3000` باز کنید.

## ساختار پروژه
- `server.js` — روت‌ها و منطق اصلی سرور
- `data/` — داده‌های خدمات، نمونه‌کارها، دوره‌ها، مقالات و... (فعلاً به‌صورت فایل JS، قابل جایگزینی با دیتابیس)
- `views/` — قالب‌های EJS (صفحات عمومی در `views/pages`، پنل مشتری در `views/pages/client`)
- `public/` — CSS و JS سمت کاربر

## ورود آزمایشی پنل مشتری
در `/client/login` هر ایمیل و رمز عبوری وارد کنید، وارد پنل نمایشی می‌شوید (فعلاً بدون دیتابیس واقعی).

## پنل ادمین
آدرس: `/admin/login`
نام کاربری/رمز پیش‌فرض: `admin` / `admin123` (در فایل `.env` با کلیدهای `ADMIN_USER` و `ADMIN_PASS` تغییر دهید)

از پنل ادمین می‌توانید:
- تمام متن‌ها، عنوان منو، متن دکمه‌ها، هیرو، درباره ما، فوتر و اطلاعات تماس را ویرایش کنید (`/admin/site-settings`)
- عکس و ویدئو آپلود و مدیریت کنید (`/admin/media`)
- خدمات، نمونه‌کارها (با عکس/ویدئو)، دوره‌ها، مقالات، نظرات مشتریان، سوالات متداول، تیم و تعرفه‌ها را افزودن/ویرایش/حذف کنید
- درخواست‌های ثبت‌شده از فرم‌های تماس، درخواست پروژه و رزرو مشاوره را مشاهده کنید (`/admin/leads/all`)

تمام این محتوا در فایل `data/db.json` ذخیره می‌شود (یک دیتابیس فایلی ساده، قابل جایگزینی با MongoDB/PostgreSQL در آینده).
فایل‌های آپلودشده در `public/uploads/` ذخیره می‌شوند.

⚠️ نکته امنیتی: قبل از انتشار واقعی سایت حتماً `ADMIN_USER`, `ADMIN_PASS` و `SESSION_SECRET` را در `.env` تغییر دهید.

## مواردی که برای فاز بعد نیاز به تصمیم دارند
- دیتابیس (MongoDB / PostgreSQL / MySQL) برای کاربران، پروژه‌ها و CRM
- درگاه پرداخت آنلاین (زرین‌پال، آی‌دی‌پی و...)
- اتصال واقعی به Instagram Graph API و WhatsApp Business API
- سرویس پیامک برای اطلاع‌رسانی
- سرویس ایمیل مارکتینگ برای خبرنامه

## ذخیره اطلاعات و استقرار روی لیارا
نیازی به دیتابیس جداگانه نیست. اطلاعات مشتریان (ثبت‌نام با رمز هش‌شده)، محتوای سایت، درخواست‌ها، فایل‌های آپلودی و نشست‌ها روی دیسک ذخیره می‌شوند.

مهم: فایل‌سیستم خود لیارا موقتی است و با هر دیپلوی پاک می‌شود. پس باید دیسک دائمی بسازید:
1. در پنل لیارا، برای اپ خود یک **دیسک** بسازید و مسیر Mount آن را مثلاً `/app/storage` بگذارید.
2. در بخش **متغیرهای محیطی** اپ این‌ها را تنظیم کنید:
   - `DATA_DIR=/app/storage`
   - `SESSION_SECRET=` یک رشته تصادفی طولانی
   - `ADMIN_USER` و `ADMIN_PASS` رمز قوی
3. دیپلوی کنید. در اولین اجرا، دیتابیس اولیه خودکار روی دیسک کپی می‌شود.

نکته: بدون ساخت دیسک و تنظیم `DATA_DIR`، ثبت‌نام‌ها با دیپلوی بعدی از بین می‌روند.
مشتریان ثبت‌نام‌شده را در `/admin/users/all` ببینید.

## فروشگاه و پرداخت
- **دوره‌ها** و **فروشگاه فیچرها** (`/store`: صدا، تصویر، قالب آماده، LUT و...) هر کدام یک «نمونه رایگان» (دانلود برای همه) و یک «فایل کامل» (فقط بعد از پرداخت) دارند.
- فایل‌های کامل در پوشه خصوصی (`DATA_DIR/private`) ذخیره می‌شوند و فقط از مسیر `/download/...` و پس از بررسی خرید قابل دانلود هستند.
- روش‌های پرداخت: درگاه آنلاین (زرین‌پال) و کارت‌به‌کارت با آپلود رسید. رسیدها در `/admin/orders` بررسی و تایید می‌شوند.
- فاکتورهای پنل مشتری هم با همین دو روش قابل پرداخت هستند.
- تنظیمات در ادمین: «متن‌ها و تنظیمات سایت ← پرداخت». مرچنت‌کد را بهتر است در متغیر `ZARINPAL_MERCHANT_ID` بگذارید.
- برای هر محصول حتماً «قیمت واقعی (عدد)» و «فایل کامل» یا «لینک دانلود کامل» را پر کنید، وگرنه دکمه خرید فعال نمی‌شود.
